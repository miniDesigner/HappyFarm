# HappyFarm 欢乐农场

一款对标《卡通农场》(Hay Day) 玩法的微信小游戏，在碎片时间里经营一片慢慢长大的田园。

## 项目简介

- **玩法循环**：种植 → 养殖 → 加工 → 订单 → 扩张
- **引擎**：原生 JavaScript ES6 模块 + Canvas 2D + requestAnimationFrame（与《占地之王》技术栈一致，零第三方引擎、零运行时依赖）
- **平台**：微信小游戏（主）/ QQ 小游戏（次）
- **后端**：腾讯云 CloudBase
- **变现**：IAP 深化（通行证/礼包/月卡/外观）+ 部分 IAA（激励视频辅助）
- **社交**：轻社交（好友互访/赠礼/轻排行/分享裂变）
- **美术**：自研，Q 版厚涂卡通
- **上线**：小范围种子用户测试后再放量

## 阶段二 Demo：本地运行

### 浏览器预览（推荐，快速验证）

```bash
# 启动预览服务器（端口 8892）
python preview-server.py
# 浏览器打开 http://localhost:8892/preview/index.html
```

### 微信开发者工具

1. 用微信开发者工具导入本项目根目录
2. 确认 `project.config.json` 中的 AppID 是你自己的小游戏 AppID
3. 编译运行

### 运行测试

```bash
node --test tests/*.test.js
```

### Demo 已实现的闭环

- 3×3 地块播种（小麦免费 / 胡萝卜 / 玉米 3 级解锁）
- 真实时间生长 + 离线成熟结算（8 小时上限）
- 收获（5% 暴击双倍）→ 仓库
- 工坊加工（小麦→面包、胡萝卜蛋糕）
- 订单交付（需求校验 + 金币/经验奖励）
- 经验升级（5 级，解锁新作物/配方）
- 本地存档（自动保存 15s / 退出保存）
- Canvas 2D 卡通渲染 + 点击交互

### 关键目录

```
game.js              微信小游戏入口桩
src/data/configs.js  全部数值配置（改这里即可调数值）
src/game/GameState.js 核心玩法逻辑
src/system/          渲染 / 输入 / 存档系统
preview/             浏览器预览环境
tests/               逻辑自动化测试
```
